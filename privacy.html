Privacy Policy — Shuo's Social Science Toolkit

Effective Date: August 16, 2026

Data Collection

This extension does not collect or store personal data on external servers. Journal matching normally uses databases bundled with the extension.

What the Extension Does

The extension reads publication metadata on supported Google Scholar, PubMed, Web of Science, Scopus, ResearchGate, and ORCID pages you visit. It displays journal quartile (JCR/SJR), index information (SCIE, SSCI, AHCI, ESCI, EI, Scopus), Impact Factor, H-index, and a fully open-access APC price tier next to journal names. Matching is performed locally after the source metadata has been resolved.

When the extension cannot determine a journal identity from its local data, it may send the visible paper title or DOI only to Crossref to obtain the journal name and ISSNs. It does not send authors, abstracts, profile identifiers, or the page's search query to Crossref.

On PubMed pages, the extension may send the visible PubMed IDs (PMIDs) only in one batch to NCBI ESummary to obtain full journal names and ISSNs. It does not send search terms, abstracts, or page content to NCBI.

The optional Citation Checker reads a Word .docx file that you explicitly choose. The document is decompressed and checked in the extension page on your device. The file and report are not uploaded or sent to Crossref.

Data Storage

The extension stores only its enabled/disabled setting and current version in Chrome's local extension storage. Crossref lookup keys and responses may be cached temporarily in service-worker memory to avoid duplicate requests; they are not written to local storage and are cleared when that worker restarts. Selected DOCX files and citation reports are kept in memory only, unless you choose to export a text report.

Permissions

The extension requests access to scholar.google.*, pubmed.ncbi.nlm.nih.gov, webofscience.com, scopus.com, researchgate.net, and orcid.org to read publication metadata; to api.crossref.org for journal-identity recovery; and to eutils.ncbi.nlm.nih.gov for PubMed journal metadata. It does not access other websites.

Third-Party Services

The extension uses the following public academic APIs:

  • Crossref (api.crossref.org) — the official DOI registration agency. No API key or authentication required.
  • NCBI E-utilities (eutils.ncbi.nlm.nih.gov) — retrieves PubMed journal names and ISSNs from visible PMIDs. No API key or authentication required for this low-volume batched use.

Only a visible publication title or DOI is transmitted to Crossref when local journal matching fails, and only visible PMIDs are transmitted to NCBI on PubMed pages. No Scholar profile identifier, author list, abstract, manuscript, browsing history, page search query, or extension-generated user identifier is sent. Like any web request, the third-party service receives ordinary network information such as the requesting IP address. No analytics, tracking, or advertising services are used.

Citation Checker Limits

The checker is an offline heuristic assistant, not a guarantee of correctness. It works best with English APA 7 author-year citations and square-bracket numeric citations. It does not fully inspect footnotes, endnotes, images, equations, PDFs, source authenticity, semantic accuracy, or every journal-specific rule.
